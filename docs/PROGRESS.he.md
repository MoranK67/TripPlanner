## מה נעשה עד עכשיו

**אבטחה**
- הפרויקט ב-GitHub פרטי.
- ההרשמה ב-Supabase סגורה, כך שרק משתמשים שתיצרי בעצמך יכולים להיכנס.
- כל משתמש רואה רק את הטיולים שלו. 366 בדיקות אוטומטיות מוודאות את זה, ובודק אבטחה עבר על הכול.
- אין סיסמאות או מפתחות סודיים בקוד.

**מסד הנתונים**
- טבלאות למשתמשים, לטיולים ולפעילויות.
- כללים שמונעים טעויות: שתי פעילויות באותה שעה, פעילות מחוץ לימי הטיול, טיול ארוך מ-90 יום.
- כשמקצרים טיול, פעילויות שכבר לא נכנסות חוזרות אוטומטית לבנק.
- כשמאריכים פעילות משובצת והיא כבר לא נכנסת, היא חוזרת לבנק בצעד אחד ובטוח.

**הלוגיקה**
- חישובי תאריכים ושעות, ותוויות בעברית כמו "שעתיים וחצי".
- כללי שיבוץ זהים לאלה של מסד הנתונים, כדי שהאפליקציה תגיד מראש אם אפשר לשבץ.
- קריאה של רשימות פעילויות שמודבקות מאקסל או מטקסט, בכל הפורמטים של אב הטיפוס ועוד.
- חישוב פריסת הלוח לייצוא כתמונה או כ-PDF.

**העיצוב (אושר על ידך)**
- כפתורים, שדות, חלונות קופצים, הודעות וחלון "האם את בטוחה?" למחיקה.
- בחירת צבעים, ובלוק פעילות כמו באב הטיפוס.
- מבנה מסך שמתאים את עצמו למחשב, לטאבלט ולטלפון.
- הכול מימין לשמאל ונגיש: מקלדת, קורא מסך וניגודיות צבעים.

**המסכים הראשונים**
- התחברות, יציאה (עם שאלת "האם לצאת?") ו"שכחתי סיסמה". אין הרשמה: רק משתמשים שאת יוצרת.
- כשמתנתקים, או כשמשתמש אחר נכנס, הנתונים של הקודם נמחקים מהזיכרון.
- רשימת טיולים, ויצירה ועריכה של טיול עם לוח שנה בעברית. כשמקצרים טיול, מופיעה הודעה כמה פעילויות חזרו לבנק.
- בנק פעילויות: הוספה, עריכה ומחיקה. כל פעילות חדשה מקבלת את הצבע הבא בתור.
- חלון לא נסגר באמצע שמירה, כדי שתמיד יופיע אם השמירה הצליחה.

**לוח הזמנים**
- מוצג בדף הטיול: ימים מימין לשמאל, חצאי שעות, אזורים אפורים מחוץ לשעות הטיול, והפעילויות המשובצות.
- לחיצה על פעילות בלוח פותחת עריכה, ו-× שואל לפני מחיקה.

**ניסוי הגרירה**

- בטלפון: לחיצה ארוכה מתחילה גרירה, והחלקה רגילה גוללת.

## איך להריץ את האפליקציה בעצמך ולבדוק את המצב

צריך לעשות את זה רק במחשב שעליו הפרויקט (התיקייה `C:\dev\trip-planner`). הכול כבר מותקן.

1. פותחים את **VS Code** על תיקיית הפרויקט.
2. פותחים חלון פקודות: בתפריט **Terminal ← New Terminal**.
3. כותבים את הפקודה הזו ולוחצים Enter:
   ```
   npm run dev
   ```
4. אחרי כמה שניות מופיעה שורה עם `http://localhost:5173`. פותחים את הכתובת הזו בדפדפן (Chrome או Edge).
5. מתחברים עם המשתמש שיצרת ב-Supabase (אימייל וסיסמה).
6. מה אפשר לבדוק: ליצור טיול, להוסיף פעילויות לבנק, ולראות את לוח הזמנים בדף הטיול. אם הגרירה כבר נשמרה (ראי בטבלה למעלה), אפשר לגרור פעילות מהבנק ללוח.
7. כדי לעצור: חוזרים לחלון הפקודות ולוחצים **Ctrl+C**.

**בדיקה בטלפון (באותה רשת Wi-Fi כמו המחשב):** במקום שלב 3 כותבים `npm run dev -- --host`. מופיעה שורה נוספת עם כתובת כמו `http://192.168.x.x:5173`, ואותה פותחים בדפדפן של הטלפון. אם Windows שואל אם לאפשר גישה לרשת, עונים "אפשר" (רשת פרטית בלבד).

**אם משהו לא עובד:**
- אם מופיעה הודעת שגיאה אדומה במקום האפליקציה, ייתכן שהעבודה נעצרה באמצע משימה והקוד עוד לא שלם. זה לא מקלקל כלום. כתבי לי "תמשיך" ואני אסיים.
- אם כתוב ש-`npm` לא מוכר, סגרי את VS Code, פתחי אותו מחדש ונסי שוב.
- אם כתוב שהפורט 5173 תפוס, האפליקציה כנראה כבר רצה בחלון אחר. אפשר פשוט לפתוח את הכתובת בדפדפן.
